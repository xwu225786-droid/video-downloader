# 本地语音识别方案归档

归档于 2026 年 11 月 24 日。此方案用于还原旧版离线转写。当前应用的语音识别使用已配置的云端 API。

## 原流程

1. FFmpeg 从视频提取 16 kHz、单声道、16 位 PCM WAV。
2. whisper.cpp 的 `whisper-cli` 加载多语言 Medium Q5_0 模型。Silero VAD 识别有人声的区间，减少静音和背景音乐误识别。
3. Whisper 输出 JSON。应用读取语言、毫秒时间戳和每段文字，通过 OpenCC 转为简体中文后拼接逐字稿，用原时间戳生成 SRT 和时间轴。
4. 下载后自动转写和卡片补提字幕共用这一流程。二者使用同一组并发限制，默认同时识别 2 条。旧版 Docker 默认为 1 条，单次 Whisper 的默认超时为 3600 秒。

## 原命令

以下是旧版等效命令，`zh` 可按需要改为其他语言代码或 `auto`。

```sh
ffmpeg -hide_banner -loglevel error -i input.mp4 -vn -ac 1 -ar 16000 -c:a pcm_s16le audio.wav
whisper-cli -m ggml-medium-q5_0.bin -f audio.wav -l zh \
  -oj -of transcript -pp -sns -mc 64 --vad -vm ggml-silero-v6.2.0.bin
```

`-pp` 输出识别进度，`-sns` 抑制非语音标记，`-mc 64` 限制文本上下文。Windows 旧实现使用仅含 ASCII 字符的临时相对路径调用 Whisper，解决中文路径在官方二进制中读取失败的问题。同一磁盘优先建立硬链接，无法链接时复制。

旧版代码可在本地源码仓库检出 `03d5b55665615ed560ad738d3b5f294929250f6e` 查阅。识别实现位于 `VoxPull/src/voxpull/infrastructure/transcriber.py`，安装参数与资源来源见 `VoxPull/scripts/bootstrap.sh`、`VoxPull/scripts/bootstrap-windows.ps1`、`VoxPull/scripts/windows-runtime.json` 和 `Dockerfile`。建议在独立目录保存旧版，避免复用正在运行的应用的数据目录。
