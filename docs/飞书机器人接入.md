# 飞书机器人接入

应用内模块已构建，默认关闭。当前完成了本地模拟、官方SDK消息解析、Docker运行和界面验证；尚未连接真实飞书应用，实际收发和后台权限联调留待配置凭证后进行。

## 本次已实现

- 设置中增加“飞书机器人”：保存应用凭证、启停接入、测试凭证、设置允许用户和群、选择群内是否需要@机器人，以及是否提取字幕。
- 使用飞书官方Python SDK 1.7.5的WebSocket长连接，在独立子进程接收消息；只将消息持久写入本机收件箱，下载和回传交给应用后台，避免阻塞事件确认。
- 支持文字分享内容及富文本超链接，每条最多10个不同链接，识别抖音、小红书和Bilibili的现有链接类型。实际下载能力和登录要求与网页入口一致。
- 私聊仅处理允许用户的消息，群聊仅处理允许群的消息；默认要求明确@当前机器人，@其他机器人或@所有人不触发。允许列表全部留空时可以连接，但不会创建下载任务，便于首次获取用户和群ID。
- 复用现有持久化处理队列，强制保留下载的视频。默认只下载并提取标题、封面；打开字幕选项后增加本机转写。飞书提交的任务也会同步显示在网页处理队列。
- 结果回复原会话：标题和原链接、封面、MP4视频、可用的文案TXT。图文作品回传图片及已提取正文，本版最多处理前20个图片资源。
- 飞书消息按消息ID去重，任务ID与消息和链接固定对应；回传按步骤保存检查点。发送失败自动退避重试，连续失败后可在设置的最近记录中点击“重试回传”。已创建的任务不会因回传重试而重新创建；被删除的任务也不会自动重建。
- 遇到抖音人工验证时，向原会话提示到运行应用的Mac上完成验证。不会自动处理验证码，也不会把本机地址当作手机可访问的验证链接。

## 明天配置飞书后台的顺序

1. 在[飞书开放平台](https://open.feishu.cn/app)创建企业自建应用，开启机器人能力，记录App ID和App Secret。在本机设置填写，凭证无需发到聊天中。
2. 为应用开通接收单聊、接收群内@消息、发送消息和上传图片/文件的权限。常用权限为`im:message.p2p_msg:readonly`、`im:message.group_at_msg:readonly`、`im:message:send_as_bot`、`im:resource`；以后台当前展示为准。只有希望群内不@也触发时，才申请接收全部群消息的权限。
3. 在本机“设置 → 飞书机器人”中保存凭证，可以先点“测试连接”检查凭证和机器人身份。测试通过不代表消息订阅和所有上传权限均已通过实际验证。
4. 在本机启用接入，允许列表可暂时留空；保持应用运行。在飞书后台选择“使用长连接接收事件”，订阅`im.message.receive_v1`，配置应用可用范围，并发布、完成相应审核。群聊场景还需将机器人加入目标群。
5. 给机器人发送一条测试文字；群聊中@机器人发送。设置下方的最近记录会显示用户Open ID和会话Chat ID。将自己的用户ID加入允许用户；需要群聊处理时，把对应群的会话ID加入允许群，再保存。首次被忽略的消息不会自动补处理，配置后重新发链接即可。
6. 先发一条短视频验证“接收 → 排队 → 下载 → 标题/封面/视频回传”，再测试字幕、群聊、验证暂停和文件超限情况。

## 文件与运行方式

- 凭证位于`VoxPull/data/auth/feishu-config.json`，文件权限600。接口只返回“已保存”状态，不返回App Secret；留空保存会保留原Secret，更换App ID需同时填写新Secret。
- 消息、任务绑定和发送检查点位于`VoxPull/data/feishu/messages.sqlite3`；私有目录权限700、数据库权限600。用于回传的TXT位于该目录下的`exports/<任务ID>/文案.txt`。
- 浏览器中的处理队列会自动发现飞书任务；消息和素材继续保存在已有Docker数据挂载中，不需要额外服务器或对外开放接收端口。
- 关闭接入会停止监听与回传，已进入处理队列的任务继续按现有逻辑处理。重新启用后，可恢复同一应用、仍在允许范围内的未完成回传。清除配置会删除已保存凭证，不删除素材和任务。

## 本版限制

- 必须保持Mac开机、联网、不休眠，Docker和应用运行。关闭期间的消息是否补推由平台机制决定，本版没有聊天历史补抓功能。
- 消息附件上传按30MiB、图片按10MiB做本地预检，仍需服从飞书服务端实际限制。超限或源文件不存在时会发说明，继续回传其他结果；不会自动压缩、切割或上传飞书云盘，原素材继续保留在本机。
- 飞书回传会将结果上传到飞书。下载、转写仍在本机完成。
- 本机中断的下载按现有规则标记失败；回传恢复不会自动重跑失败下载。重新发送链接可启动新任务。网页单独重试产生的新任务暂未绑定到原飞书消息，需重新发链接才能完成新的自动回传。
- 目前只回复来源会话。群内提交后改为私发个人、云盘大文件分享等能力尚未实现。
